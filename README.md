# Renata Messias — Skin Concept

Site institucional (estático, HTML/CSS puro, sem build).

## Estrutura
- `index.html` — todas as seções do site
- `styles.css` — estilos
- `assets/` — imagens usadas no site
- `preview.jpg` — imagem usada no og:image (preview de compartilhamento)

## Rodar localmente
Basta abrir o `index.html` no navegador. Não precisa de servidor nem build.

## Publicar / atualizar na Vercel
Repositório conectado à Vercel — qualquer `git push` na branch principal já gera um novo deploy automaticamente.
